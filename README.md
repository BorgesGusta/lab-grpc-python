# lab-grpc-python

Repositório de experimentos práticos sobre **RPC (Remote Procedure Call)** utilizando Python, explorando implementações nativas e os padrões de gRPC com Protocol Buffers.

## 📁 Experimentos

* **[`01-xml-rpc-basico/`](./01-xml-rpc-basico)**: Comunicação cliente-servidor simples com `xmlrpc`.
* **[`02-grpc-unary/`](./02-grpc-unary)**: Chamada de procedimento remoto padrão (Unary RPC).
* **[`03-grpc-streaming/`](./03-grpc-streaming)**: Server Streaming RPC (fluxo contínuo do servidor para o cliente).
* **[`04-grpc-bidirectional/`](./04-grpc-bidirectional)**: Bidirectional Streaming RPC (chat interativo em tempo real de mão dupla).

## 🚀 Como Executar

Clone o repositório, configure o ambiente virtual, instale as dependências e execute os scripts de cada pasta (`servidor.py` seguido de `cliente.py`) em terminais separados.
